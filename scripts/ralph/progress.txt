## Codebase Patterns
- Tauri v2: Use `#[tauri::command]` in lib.rs, `State<'_, DataDirState>` for data dir, open fresh `rusqlite::Connection` per command
- SQLite: `CREATE TABLE IF NOT EXISTS`, `INSERT OR IGNORE` for seed data, `PRAGMA foreign_keys = ON`
- Frontend: Vanilla JS hash routing `#/route`, lazy-loaded page modules via `import()`, `t(key, params)` for i18n
- API layer: `invoke("command_name", { args })` in api.js wrappers, JSON.parse the string result
- Character stats: `CharacterRecord` has hp, atk, def, crit_rate, crit_dmg, pen_ratio, anomaly_mastery, anomaly_proficiency, energy_regen, impact
- WEngine stats: `WEngineRecord` has atk, crit_rate, crit_dmg, pen_ratio, energy_regen, impact, anomaly_mastery
