## Codebase Patterns
- **JS form labels use `t()` at render time**: labels are frozen - no `data-i18n` on dynamic forms. To make them reactive, must re-render on `langchange`.
- **Characters form is built manually in `createCharForm()`**: not using the generic `createForm()` component - uses inline `addField()` helper + manual event listeners.
- **Number inputs in `addField()`**: use `step` param to control precision. Use `step: "any"` for unrestricted decimal input.
- **`validate()` returns `null` on success, error string on failure**: do NOT negate the result with `!` when checking for errors in conditions.
- **schema change propagation**: Adding a column requires updates to: db.rs (CREATE TABLE), zsim-core entity struct, src-tauri CharacterRecord struct, row mapper, all SELECT queries, all INSERT/UPSERT (columns + params), import.rs INSERT, export.rs SELECT+Character construction, loader.rs SELECT+Character construction, and optionally test data JSON strings.
- **zsim-core entities**: Used by import.rs/export.rs/loader.rs for JSON deserialization. Changes to entity structs cascade to all these crates.
- **Ralph for opencode**: prompt-opencode.md is the instruction file. CLI tool is `opencode` with `--agent build`. CLAUDE.md is read by opencode as context when navigating to the directory.
