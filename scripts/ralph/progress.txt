## Codebase Patterns
- **JS form labels use `t()` at render time**: labels are frozen - no `data-i18n` on dynamic forms. To make them reactive, must re-render on `langchange`.
- **Characters form is built manually in `createCharForm()`**: not using the generic `createForm()` component - uses inline `addField()` helper + manual event listeners.
- **Number inputs in `addField()`**: use `step` param to control precision. Use `step: "any"` for unrestricted decimal input.
- **`validate()` returns `null` on success, error string on failure**: do NOT negate the result with `!` when checking for errors in conditions.
