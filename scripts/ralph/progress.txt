## Codebase Patterns
- ElementTag is a fieldless enum, derive Copy + Clone to avoid unnecessary .clone() calls.
- AnomalyDisorderManager pattern: `states: HashMap<String, Vec<AnomalyState>>` per-enemy, lazy-slot-creation per element. Borrow split trick: read gauge in a block, drop mutable borrow, then call &self methods before resuming mutation.
- AnomalyState stores `gauge_at_trigger` for disorder damage calculations. If the new element has no AnomalyState slot yet, gauge is treated as 0.0 for disorder calcs.
- AccumulateResult/TriggerAnomalyResult/DisorderResult structs provide structured feedback without coupling to the event bus.
- Ralph tracking files are at `scripts/ralph/prd.json` and `scripts/ralph/progress.txt`. The `ralph/` directory at project root is a separate Claude Code plugin repo with its own `.git`.
- Rust toolchain: Always use `stable-x86_64-pc-windows-gnu` as default. The MSVC toolchain builds cached artifacts but fails when rebuilds are needed because `link.exe` from Git for Windows shadows the MSVC linker. `rustup default stable-x86_64-pc-windows-gnu` fixes this.
- When using `data` in a struct literal like `ActiveBuff { data, remaining_ticks: data.duration_ticks }`, read the field BEFORE the move: `let duration = data.duration_ticks; ActiveBuff { data, remaining_ticks: duration, ... }`.
- Damage calculation modules: Use unit structs with `fn calc(&self, input: &CalcInput, rng: &mut RNGManager) -> CalcOutput` signature. CalcInput has Default impl with safe defaults (res_factor=1.0, anomaly_threshold=100.0).
- Defense formula: `effective_def = (def * (1 - pen_ratio) - pen).max(0.0)` and `def_factor = 1.0 / (1.0 + effective_def / 1000.0)`.
- Anomaly damage never crits. Proficiency factor = `1 + anomaly_proficiency / 100`.
- Anomaly accumulation: `gauge_added = anomaly_mastery * multiplier`, trigger at threshold.
- Stun is deterministic (no RNG). Resources/DR also have no RNG dependency.

## 2026-05-02 11:00 - US-005
- Implemented 6 damage calculation modules in zsim-core/src/calculation/damage.rs
- RegularMul: ATK × multiplier × (1+DMG_BONUS) × crit_factor × def_factor × res_factor × (1-DR)
  - Effective DEF = DEF×(1-PEN_RATIO)-PEN, clamped to 0; def_factor = 1/(1+effective_DEF/1000)
  - Uses RNG for crit check; crit_factor = 1.0 (non-crit) or 1+CRIT_DMG (crit)
- AnomalyMul: ATK × anomaly_multiplier × (1+proficiency/100) × (1+anomaly_dmg_bonus) — never crits
- StunMul: IMPACT × daze_multiplier × (1+daze_bonus) × (1-daze_resistance) — deterministic
- CalAnomaly: gauge_added = anomaly_mastery × multiplier; triggered = cumulative_gauge ≥ threshold
- CalDisorder: (old_gauge + new_gauge) × disorder_multiplier
- CalPolarityDisorder: same as CalDisorder × 1.5 (polarity factor)
- CalcInput: shared input struct with Default impl (all 20+ fields, safe defaults)
- CalcOutput: shared output struct with damage/is_crit/stun_damage/anomaly_gauge/triggered_anomaly
- 20 new tests: basic calculations, crit/pen/resist/DR, proficiency scaling, gauge threshold, disorder, polarity ratio, determinism, precision ≤ 1e-9

- **Learnings for future iterations:**
